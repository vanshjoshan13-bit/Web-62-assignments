Student Task Manager

Project type: Web Application

1. Project Idea

Student Task Manager is a simple web application that helps students organize assignments, study tasks, and daily activities.

2. Project Objectives

  • Organize daily study tasks.
  • Track completed and pending work.
  • Provide a simple, responsive user interface.
  • Save tasks in browser storage in a later development stage.

3. Core Features

Add Tasks Complete Tasks Delete Tasks Filter Tasks Save Tasks

4. User Requirements

  1. The user can enter a task name.
  2. The application rejects empty tasks.
  3. The user can mark a task completed.
  4. The user can delete an unwanted task.
  5. The interface works on desktop and mobile screens.

5. Technology Used

  • HTML for page structure
  • CSS for styling and responsive layout
  • JavaScript for task operations
  • localStorage for browser-side persistence in a later stage

6. Expected Outcome

A user-friendly application that helps students manage study activities from a browser.
