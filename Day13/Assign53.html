Student Task Manager — Architecture Notes

1. Project Structure

  • index.html — webpage structure
  • style.css — design and responsive layout
  • script.js — application logic and event handling
  • taskUtils.js — reusable task utility functions

2. Application Flow

  1. The HTML file creates the interface.
  2. The CSS file styles the interface.
  3. JavaScript receives user actions.
  4. Utility functions validate and process task data.
  5. The interface updates to display the latest task list.

3. Data Structure

Each task is stored as a JavaScript object:

{
  id: 1,
  title: "Complete assignment",
  completed: false
}

4. Validation Rules

  • Task titles cannot be empty.
  • Every task must have a unique ID.
  • The completed property must be a boolean.

5. Future Improvements

  • Save tasks using localStorage.
  • Add edit and filter options.
  • Provide automated test cases.
